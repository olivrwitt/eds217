Dataset: We used the Kaggle Spotify dataset for our analyses, accessed at:
 https://www.kaggle.com/datasets/maharshipandya/-spotify-tracks-dataset
This dataset contains information on roughly 232,000 songs on spotify.  In additon to song name, genre, and artist; this dataset includes information on popularity, tempo, key, mode, speechiness, song length, and more.  We used this dataset to answer the below questions:


1. What is the difference in tempo across pop, rap, classical, and opera music?
2. What is the most popular key across all genres?
3. Does Acapella music have more speechiness than other genres?
4. What genres have the longest songs, and how does song length relate to popularity?
